# Pretrained model files

Download the following Hugging Face snapshots before running the protein
language-model experiments:

- `facebook/esm2_t12_35M_UR50D` to `pretrained/esm2_t12_35M_UR50D/`
- `Rostlab/prot_bert` to `pretrained/prot_bert/`

Model weights are excluded from Git because they exceed GitHub's regular file
size limit. Configuration and tokenizer files may remain in their respective
directories.
